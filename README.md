# マラソン大会ファインダー

国内のフル・ハーフ・イベント系ランと海外の都市フルマラソン（2026-27シーズン〜2027年）を、エントリー日・抽選/先着・エントリー状況つきで検索できる一覧サイトです。コース・エイド・参加賞・口コミ・友達と出る方法などの詳細も見られます。

https://runners-hub.github.io/marathon-race-finder/

## できること

- 大会ごとに「カレンダーに追加」（受付開始・締切・本番を Google カレンダーに登録）
- 「カレンダー」タブでマイリストの予定を月ごとに一覧・.ics ファイルでまとめて保存

- エントリー受付中 / 開始前 / 終了 / 未発表 のひと目判定
- 抽選・先着、開催月、地方、レース特徴（記録狙い/ファンラン）での絞り込み
- 開催日順・エントリー開始日順・人気順の並び替え
- 各大会の公式サイトへのリンク

## データについて

- 掲載情報は各大会公式サイト等の調査に基づく参考情報です。週1回の巡回チェックで更新しています
- エントリー前に必ず大会公式サイトで最新情報をご確認ください
- 人気・レース特徴の評価は運営者の主観です
- 誤りを見つけたら Issue で教えてください
